- For a reaction that is zero order in A (n = 0):
$$C_A(t) = -kt + CA_0 $$
- For a reaction that is first order in A (n = 1):
$$ lnC_A(t) = -kt + lnCA_0 $$
- For a reaction that is second order in A (n = 2):
$$ {1 \over C_A(t)} = kt + {1 \over C_{A_0}}$$
