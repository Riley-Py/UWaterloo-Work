### Ternary Operator
- Takes three operands
	- Condition
	- Value-if-true
	- Value-if-false
- General structure: ``condition ? true : false``
- Good for simple choices
- Bad for nesting

### Looping - Part 2
- ``for...of`` is going through items in collection; works on arrays, strings, maps, sets, anything iterable
	- For both value and index, use ``entries()``
	- ``foreach`` and ``for...of`` do the same thing
- ``for...in`` - for objects walking through property names
	- Gives you key; to get value, must access it with the key
		- Example: ``user[key]``
	- Don't use these on an array ever; only on objects
### Global Object
- Called different things in different contexts
	- *Browser* - ``window``
	- *Node.js* - ``global``
	- *JavaScript* - ``globalThis``
		- Never use this; can overwrite data in the same place
### Throwing Errors
- When something goes wrong
	- Stops the function
	- Propagates up call stack
- In Python, this is ``raise``

#### Built-in Errors
- ``error`` - generic
- ``TypeError`` - value for wrong type
- ``RangeError`` - number outside of allowed range
- ``ReferenceError`` - variable that doesn't exist; generated at runtime
- ``SyntaxError`` - code doesn't parse; generated by parser

### Try/Catch/Finally
- ``try`` - trying risky code
	- If anything throws error, execution goes to ``catch``
- ``catch (err)`` - receives error
	- ``err.message`` is message that is passed to ``new Error(err)``; ``err.stack`` shows call path
- ``finally``- runs whether or not error occured
	- Use for cleanup
	- Optional
- Only for synchronous errors
	- Code that runs immediately
