- Formula: $$P = {{C \over (1 + {YTM})} + {C\over(1+YTM)^2} + \dots + {C\over(1 + YTM)^n} + {M\over(1+YTM)^n}}$$
- Where:
	- $P$ is present value
	- ${YTM}$ is Yield-To-Maturity
	- $C$ is coupon payment
	- $M$ is value at maturity (face value)
	- $n$ is number of periods
