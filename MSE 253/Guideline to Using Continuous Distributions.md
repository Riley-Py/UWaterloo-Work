## Uniform
- Every value in an interval is equally likely

## Normal
- Measurements influenced by many small independent factors

## Exponential
- Time until first event in a poisson process
- Special case of the gamma distribution

## Gamma
- Time until the k-th event in a poisson process

## Lognormal
- Variable is produced only with positive factors

- Only use in conjunction with normal if and only if
	1. Need only positive values
