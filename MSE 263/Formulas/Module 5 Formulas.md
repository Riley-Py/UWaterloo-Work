*Cobb-Douglas Production Function*: $$q = f(L, K) = L^{0.5} K^{0.5}$$
*Average product of labor*: $$AP_L = {Q \over L}$$
*Marginal product of labor*: $$MP_L = {{\Delta q} \over \Delta L}$$
*Isoquant*: $$\bar q = f(K, L)$$
*Marginal Rate of Technical Substitution (MRTS)*: $${\Delta K \over \Delta L}$$
*Linear production function*: $$q = f(L, K) = aL + bK$$
*Leontief production function*: $$q = f(L, K) = {min} [aL, bK]$$
*Cobb-Douglas Production Function (general form)*: $$ q = f(L, K) = AL^{\alpha}K^{\beta}$$
