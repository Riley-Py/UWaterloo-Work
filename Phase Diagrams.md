- **Intensive properties**: temperature, pressure, density, molar composition, [[Enthalpy of Vaporization|vapour enthalpy]], [[Enthalpy of Fusion + Enthalpy of Sublimation|fusion + sublimination enthalpy]] (don't depend on how much phase there is)
- **Extensive properties**: surface area, mass, volume, weight of phase (increases with amount of phase available)
**Gibbs Phase Rule**:
$$F = C - P + 2$$
where:

- C is number of different components (species) present in system
- P is number of different phases
- F is minimum number of intensive properties that must be known in order to determine all other intensive properties
