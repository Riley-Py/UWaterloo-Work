## Future Value Factor

$$ F = P (1+i)^n = P(F/P, i, n)$$
Where:
- $(F/P, i, n) = (1+i)^n$
- $F$ is future value (i.e. the value you get today)
- $P$ is present value (i.e. the value you need to put in to get to future value)
- $i$ is the interest rate
- $n$ is number of compounding instances
- Also called *compounding factor*

## Present Value Factor
$$P = F(1+i)^{-n} = F(P/F, i, n)$$
Where:
- $(P/F, i, n) = (1+i)^{-n}$
- The same variables as in the future value factor
- Also called *discounting factor*
