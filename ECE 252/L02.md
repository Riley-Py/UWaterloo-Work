- To execute a program, you need few things
	1. *Main memory* - place where instructions and data are stored
	2. *System bus* - way for instructions/data to travel between memory and processor
	3. *Processor* - element of system that executes instructions
### Processor
- *CPU* - brains of computer
	- Fetches instructions from memory via bus, decodes instruction, and executes it
		- Repeats until program is finished
- Different steps can be executed in parallel
	- One instruction is executed, another is decoded, and another is fetched
	- Called *pipeline*
- *Word* - largest unit on processor
	- 64-bit processor has word size 64 bits
- CPU instructions are specific to processor
	- Some operations are only in "supervisor mode" and not "user mode"
		- Attempting to run supervisor operations in user mode results in error
- *Registers* - storage locations of CPU
	- Can store data/instructions
	- Management is done by OS
	- Holds key variables/temporary results
	- Word-sized
### Interrupts
- Signal to processor requiring immediate attention
- Can come from many sources
	- *Program* - something happens in program
	- *Timer* - configured timer within processor time expires
	- *Input/Output* - I/O controller signals (un)successful completion of operation
	- *Hardware Failure*
- Improves processor utilization
	- CPU should always be doing something
- Can be ignored, but it is rare
