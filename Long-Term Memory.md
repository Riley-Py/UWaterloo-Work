- Storing large amounts of information for indefinite periods of time
## Long-Term Memory - Capacity
- Unlimited capacity, but some believe that it can hold $10^{13}$ or $10^{20}$ distinct bits of information
## Long-Term Memory - Coding
- Errors made by recalling from LTM are from words/phrases being recalled being similar to other words/phrases actually present
- Studies showed that acoustic similarity produced little effect on performance, but the list of semantically similar words was harder to learn
- *acoustic similarity affects STM;  semantically similarity affects LTM*
## Long-Term Memory - Retention Duration
- Can last decades to a lifetime
- Studies showed that declining memory eventually plateaus and then no more forgetting happens (for recalling languages)
## Long-Term Memory - Forgetting
- Ebbinghaus, after doing an experiment involving memory, plotted a forgetting curve, where he assumed that the more forgetting, the more effort it would take to relearn the list
	- Forgetting is rapid at first and then levels off ![[Pasted image 20250408130914.png]]
- *Paired associates learning* - participants hear lists of pairs of words, and then the experimenter presents the first word in each pair
	- *Proactive Interference* - previous learning can make retention of subsequent learning more difficult
